# Tmux 配置

一套简洁高效的 tmux 配置，使用 Solarized 配色方案。

## 前缀键

| 快捷键 | 说明 |
|--------|------|
| `Ctrl+f` | 前缀键（默认 `Ctrl+b` 已禁用） |

## 面板操作

| 快捷键 | 说明 |
|--------|------|
| `Prefix + -` | 垂直方向新增面板（上下分） |
| `Prefix + =` | 水平方向新增面板（左右分） |
| `Prefix + h` | 切换到左侧面板 |
| `Prefix + j` | 切换到下方面板 |
| `Prefix + k` | 切换到上方面板 |
| `Prefix + l` | 切换到右侧面板 |
| `Prefix + Ctrl+h` | 向左调整面板边界 5 格 |
| `Prefix + Ctrl+j` | 向下调整面板边界 5 格 |
| `Prefix + Ctrl+k` | 向上调整面板边界 5 格 |
| `Prefix + Ctrl+l` | 向右调整面板边界 5 格 |
| `Prefix + e` | 关闭除当前面板外的所有面板 |

## 窗口操作

| 快捷键 | 说明 |
|--------|------|
| `Ctrl+Shift+Left` | 将当前窗口向左移动 |
| `Ctrl+Shift+Right` | 将当前窗口向右移动 |

## 实用工具

| 快捷键 | 说明 |
|--------|------|
| `Prefix + r` | 重新加载配置文件 |
| `Prefix + o` | 在系统文件管理器中打开当前目录 |
| `Prefix + g` | 弹出 lazygit 界面（80% 宽高） |

## 其他设置

- **鼠标支持**: 已启用，可用鼠标点击选择面板、调整大小
- **复制模式**: 使用 vi 键位
- **ESC 延迟**: 设置为 10ms，提升 Vim 响应速度
- **历史记录**: 限制为 64096 行
- **真彩色支持**: 已启用
- **Undercurl**: macOS 下支持波浪下划线

## 文件结构

```
tmux/
├── tmux.conf        # 主配置文件
├── macos.conf       # macOS 特定配置
├── statusline.conf  # 状态栏样式
└── utility.conf     # 实用工具绑定
```
